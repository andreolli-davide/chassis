# 1.0.0b2 candidate review

Review date: **2026-09-24**. This is a source-tree candidate, not a published
release or a maintainer sign-off. The published beta remains `1.0.0b1`; the
latest stable release remains `0.9.1`.

## Scope

The b2 candidate addresses the defects found in the b1 audit: sibling-scope
policy and secret leakage, mutable provider selection for old generations,
spoofable LangGraph identity metadata, collapsed duplicate plugin entries in
snapshots, non-transactional agent registration, inconsistent instance config,
missing live-replay fallback capture, partial cooperative budget charges,
invalid transform returns ignoring hook failure policy, and boolean config
versions. Each fix has a regression test and a separate commit.

Snapshot format 1 gains an optional `plugin_entries` field. Existing b1 snapshot
and replay records remain readable and round-trip exactly. The b2 API and
persisted-format candidates are checked in separately from the historical b1
baselines. See [migration.md](migration.md#100b1-100b2) for behavior changes.

## Local validation

On Python 3.12.13, the candidate passed 970 tests, Ruff lint and formatting,
Pyright, a strict MkDocs build, `uv lock --check`, the 0.8.1/b1/b2 API
compatibility checks, the b2 fixture generator check, and an offline wheel and
sdist build. Branch coverage is 91.6%, above the 91% global floor; all focused
coverage floors passed. The generated distributions are named
`chassis_harness-1.0.0b2`. A local dependency audit found no known
vulnerabilities among auditable dependencies; it could not look up the
unpublished `chassis-harness==1.0.0b2` package on PyPI.
