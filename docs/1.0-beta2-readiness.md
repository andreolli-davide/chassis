# 1.0.0b2 release review

Review date: **2026-09-24**. Published as **`1.0.0b2`** / tag **`v1.0.0b2`**.
The latest stable release remains `0.9.1`. The maintainer requested this beta
release after reviewing the candidate.

## Scope

The b2 release addresses the defects found in the b1 audit: sibling-scope
policy and secret leakage, mutable provider selection for old generations,
spoofable LangGraph identity metadata, collapsed duplicate plugin entries in
snapshots, non-transactional agent registration, inconsistent instance config,
missing live-replay fallback capture, partial cooperative budget charges,
invalid transform returns ignoring hook failure policy, and boolean config
versions. Each fix has a regression test and a separate commit.

Snapshot format 1 gains an optional `plugin_entries` field. Existing b1 snapshot
and replay records remain readable and round-trip exactly. The b2 API and
persisted-format candidates are checked in separately from the historical b1
baselines. See [migration.md](migration.md#100b1-100b2) for behavior changes.

## Local validation

On Python 3.12.13, the candidate passed 970 tests, Ruff lint and formatting,
Pyright, a strict MkDocs build, `uv lock --check`, the 0.8.1/b1/b2 API
compatibility checks, the b2 fixture generator check, and an offline wheel and
sdist build. Branch coverage is 91.6%, above the 91% global floor; all focused
coverage floors passed. The generated distributions are named
`chassis_harness-1.0.0b2`. A local dependency audit before publication found no
known vulnerabilities among auditable dependencies; it could not look up the
then-unpublished `chassis-harness==1.0.0b2` package on PyPI.

## Publication controls

- The hosted release workflow runs the Python 3.12/3.13 CI matrix, including
  minimum/latest dependency, package-install, documentation, coverage, and
  dependency-audit jobs before publication.
- A dry run assembles a wheel, sdist, checksums, and SBOM for review before the
  tag. The tag workflow rebuilds and verifies its own bundle from the exact
  tagged source before publishing to [PyPI](https://pypi.org/project/chassis-harness/1.0.0b2/)
  and the [GitHub prerelease](https://github.com/andreolli-davide/chassis/releases/tag/v1.0.0b2).
- The beta documentation homepage is deployed separately after package and
  GitHub publication; the `0.9.1` stable archive remains available.

The permanent 1.0 API/format baselines, versioned documentation hosting,
public-index canaries, and final support/governance review remain **1.0.0 final**
gates, not claims made by this beta candidate.
